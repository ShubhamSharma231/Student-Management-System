# Student Management System

A full-stack Student Management System built using HTML, CSS, JavaScript, Node.js, Express.js, and MySQL.

## 📌 Project Overview

The Student Management System is a web-based application designed to manage student information efficiently.

It provides secure login authentication and allows authorized users to add, view, edit, search, filter, sort, and delete student records through a responsive dashboard.

## ✨ Features

- 🔐 Secure Login Authentication
- 🛡️ JWT-based Authentication
- 🚫 Login Rate Limiting
- 🔑 Forgot Password & Reset Password
- 👨‍🎓 Add Student
- ✏️ Edit Student
- 👁️ View Student Details
- 🗑️ Delete Student
- 🔎 Search Students
- 📚 Course Filtering
- 🎓 Year Filtering
- ↕️ Student Sorting
- 📄 Pagination
- 📊 Dashboard Statistics
- 📱 Responsive Design
- 🗄️ MySQL Database
- 🔒 Environment Variable Protection
